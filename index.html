数据更新

国外数据由 GitHub Actions 每小时抓取，国内数据由云函数每小时抓取，两者都发布到腾讯云 COS。下方为远程数据地址，每行一个，全部并行拉取后合并去重（COS 主用 → jsDelivr 备用 → raw.githubusercontent）；清空则只用内置数据。

改完点「保存设置」。COS 地址格式：https://你的桶名.cos.ap-guangzhou.myqcloud.com/data/daily.json

关于

资讯雷达 · 数据来自公开 RSS / API（GitHub 动态、Hacker News、GitHub Trending、Reddit、Google/Bing News 及 36氪、量子位、InfoQ、IT之家、中新网、百度热搜/电影榜、B站等公开源）。所有资讯均在 App 内阅读，不跳转外部浏览器；英文内容自动预翻译为中文，未预翻译的可点「译」实时翻译；同一事件的多源报道会自动聚合；AI 一眼预览与单条摘要由你配置的接口按需生成；已读与收藏仅存于本机。
